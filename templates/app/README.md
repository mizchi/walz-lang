# Walz application

English | [日本語](README.ja.md)

An application generated by `walz new`. Walz extends WAT's S-expressions with checked high-level forms and Wasm GC data.

```sh
walz check src/main.walz
walz run                    # 42
walz build                  # target/main.wasm
walz test                   # tests/**/*.test.walz
walz bench --list            # check and list app_bench.walz
walz bench --samples 10
```

Use a Wasm GC-capable Wasmtime for `run` and the default tests. Benchmarks and `--target core-js` need Node.js 24+. Building and checking this template require only the installed `walz` CLI.

| File | Purpose |
| --- | --- |
| `src/main.walz` | Entry module, exporting `main` to Wasm |
| `src/math.walz` | Reusable library with an explicit Walz source API |
| `tests/math.test.walz` | Tests that select the library's public functions |
| `app_bench.walz` | Benchmark with an input that changes each iteration |
| [CHEATSHEET.md](CHEATSHEET.md) | English syntax reference |
| [CHEATSHEET.ja.md](CHEATSHEET.ja.md) | Japanese syntax reference |
| [.agents/skills/walz/SKILL.md](.agents/skills/walz/SKILL.md) | Self-contained skill for reading and writing Walz |

Run commands from this directory. `walz build` and `walz run` find `src/main.walz` automatically. Library files use `@export` and `@use`; WAT `import`/`export` describe the host/generated Wasm boundary instead.

For a JS bundle, use `walz build --target core-js -o dist/app`; for a Component, use `walz build --target component`. See the [Walz documentation](https://github.com/mizchi/walz-lang/blob/main/docs/README.md) for host imports, Vite, the TS7 Content Mapper, and supported ABI values.

The benchmark demonstrates the CLI workflow. Such a small operation can be dominated by runner overhead; measure a useful workload before drawing performance conclusions.

Codex can discover the project-local skill in `.agents/skills`. For another compatible agent, install that `walz` folder in its skill directory; all required references are included. No global agent configuration is changed by the generator.
