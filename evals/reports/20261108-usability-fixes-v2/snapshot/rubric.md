# 試用の観点 v1

点数は0=完了不能、1=実装探索や大きな迂回が必要、2=完了できるが反復する負担、3=小さな資料確認で使える、4=局所的に迷わず使える。
軸は「入口の発見」「処理の表現」「型と所有権」「診断からの復旧」「変更の局所性」「ホスト接続」。平均で弱い項目を相殺せず、各点に実際のソース行・診断・コマンドの根拠を付ける。
LOC・括弧深さ・型引数の反復は補助指標であり、その値だけで採点しない。括弧そのものや明示moveを欠点とせず、処理を追う際に何度別の箇所を見る必要があったかを述べる。
経験者一人の試用から、初学者の成功率、統計的改善、他言語より何倍速く書ける等は主張しない。
